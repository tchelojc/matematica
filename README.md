# Fluxo Matemático - Universo Áureo

Este projeto implementa o **Fluxo Matemático**, um sistema que unifica matemática clássica, física quântica, geometria sagrada e as constantes fundamentais (0,18; 0,54; 1,80; φ; π; etc.) em uma plataforma interativa com Streamlit.

## Funcionalidades

- Cálculos duais (clássico vs fluxo)
- Visualizações 3D do tempo espiralado
- Simulador de acelerador de partículas
- Validação de padrões com constantes universais
- Relógio quântico e calendário cósmico
- Interface amigável e explicativa
